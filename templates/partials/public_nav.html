{% comment %} The drawer and its backdrop sit OUTSIDE
deliberately. The nav has `backdrop-blur`, and a non-none backdrop-filter makes an element a containing block for fixed-position descendants — so a `fixed` drawer nested inside would anchor to the nav bar instead of the viewport, and `bottom-0` would collapse. Open/closed state lives in plain CSS in base.html (`.is-open`), not in Tailwind utilities, so the panel cannot be left showing if the Play CDN fails to compile. Both are pinned to `top-16` (the nav's h-16) so the panel slides in beneath the header rather than fighting it for the same space. {% endcomment %}
